# Awesome My Workspace

> 一个精选的 AI 工具、框架和资源集合，服务于经济研究和学术工作流

## 📚 项目导航

### 🎯 核心资源库

#### [awesome-ai-for-economists](https://github.com/cupbid-lang/awesome-ai-for-economists)
- **地位**: 由 OpenEcon 团队维护的最权威目录
- **内容**: 经济学研究、政策分析与教学中各个环节的 Agent 框架、代码库与大模型微调指南
- **特色**: 附带 Wiki/GitHub Pages 充当领域最佳实践的知识库
- **主页**: https://openecon.ai

#### [awesome-econ-ai-stuff](https://github.com/cupbid-lang/awesome-econ-ai-stuff)
- **特点**: 高度模块化设计
- **内容**: 将经济学家的日常工作拆解为具体的"AI Skills"
- **应用**: 直接从中 pull 特定模块到自己的 Agent，如：
  - Stata 脏数据清洗模块
  - R 语言断点回归（RDD）自动化诊断模块
  - LaTeX 复杂经济模型排版模块
- **主页**: https://meleantonio.github.io/awesome-econ-ai-stuff/

### 🛠️ 工作流工具

#### [claude-code-my-workflow](https://github.com/cupbid-lang/claude-code-my-workflow)
- **用途**: Claude Code 学术工作流模板
- **特色**: 
  - 支持 LaTeX/Beamer + R
  - 多 Agent 审查
  - 质量门禁
  - 对抗性 QA
  - 复现协议
- **许可**: MIT License

#### [Shared-Workspace](https://github.com/cupbid-lang/Shared-Workspace)
- **功能**: Obsidian & AI Agent 工作空间
- **用途**: 集成 Obsidian 笔记和 AI Agent 工具的协作环境
- **原项目**: [RayLee1997/Shared-Workspace](https://github.com/RayLee1997/Shared-Workspace)
